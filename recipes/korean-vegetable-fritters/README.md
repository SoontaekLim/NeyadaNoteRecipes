# 야채튀김

![야채튀김 cover](images/cover.webp)

고구마, 양파, 당근, 애호박, 대파를 가늘게 썰어 차가운 반죽에 가볍게 버무린 뒤 바삭하게 튀기는 분식집 스타일 야채튀김입니다.

- 분량: 2인분
- 분류: 간식/디저트, 한식

## 재료

- 고구마 — 1/2개 (약 120g)
- 양파 — 1/2개 (약 100g)
- 당근 — 1/2개 (약 70g)
- 애호박 — 1/3개 (약 100g)
- 대파 — 1/2대 (약 35g)
- 튀김가루 — 120g (반죽 100g, 채소 덧가루 20g)
- 차가운 물 — 140ml (반죽용)
- 식용유 — 약 700ml (튀김용, 냄비에 따라 조절)
- 진간장 — 1큰술 (찍어 먹는 소스용)
- 식초 — 1작은술 (찍어 먹는 소스용)
- 물 — 1큰술 (찍어 먹는 소스용)

## 조리 방법

1. 고구마 1/2개와 당근 1/2개는 껍질을 벗깁니다. 고구마, 당근, 양파 1/2개, 애호박 1/3개를 길이 약 5cm, 굵기 3mm의 가는 채로 썰고 대파 1/2대도 비슷한 길이로 썹니다. 채소의 겉물기를 키친타월로 충분히 닦습니다.

2. 볼에 튀김가루 100g과 차가운 물 140ml를 넣고 젓가락으로 10~15번만 가볍게 섞습니다. 작은 가루 덩어리가 조금 남아 있어도 괜찮으며, 반죽은 튀기기 직전에 만듭니다.

3. 손질한 채소에 남겨둔 튀김가루 20g을 골고루 뿌려 가볍게 섞습니다. 2단계 반죽을 붓고 채소에 얇게 묻을 정도로만 2~3번 뒤집어 버무립니다.

4. 깊은 냄비에 식용유 약 700ml를 붓되 냄비 높이의 절반을 넘기지 않고 170~175°C로 달굽니다. 채소 반죽을 한 번에 2큰술씩 느슨하게 모아 6~8개로 나누어 넣습니다. 한꺼번에 많이 넣지 말고 3~4분간 중간에 한 번 뒤집어 노릇해지고 고구마까지 익도록 튀깁니다.

5. 튀긴 야채튀김은 철망에 올려 1~2분 기름을 뺍니다. 진간장 1큰술, 식초 1작은술, 물 1큰술을 섞어 찍어 먹는 소스를 만들고, 바삭할 때 바로 냅니다.
