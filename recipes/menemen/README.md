# 메네멘 (튀르키예식 토마토 달걀볶음)

토마토와 초록 피망을 부드럽게 볶다가 달걀을 넣어 촉촉하게 익히는 튀르키예식 아침·브런치 요리입니다.

- 분량: 2인분
- 분류: 메인 요리

## 재료

- 달걀 — 4개
- 토마토 — 3개 (약 350g)
- 초록 피망 (또는 뾰족 파프리카) — 1개 (약 100g)
- 양파 (선택) — 1/2개 (약 75g)
- 올리브오일 — 2큰술
- 파프리카 가루 — 1/2작은술
- 소금 — 1/2작은술
- 후춧가루 — 1/4작은술
- 바게트 또는 빵 — 2조각 (약 120g)

## 조리 방법

1. 토마토 3개를 작은 깍둑썰기로, 초록 피망 1개는 얇게 썹니다. 양파를 사용한다면 1/2개를 잘게 다지고, 달걀 4개는 작은 그릇에 깨뜨려 둡니다.

2. 넓은 팬에 올리브오일 2큰술을 중불로 달군 뒤 초록 피망과 선택한 양파를 넣고 4~5분 볶아 부드럽게 만듭니다.

3. 토마토와 파프리카 가루 1/2작은술, 소금 1/2작은술, 후춧가루 1/4작은술을 넣습니다. 중불에서 6~8분 끓여 토마토가 무르고 국물이 조금 걸쭉해지도록 합니다.

4. 불을 약불로 줄이고 달걀 4개를 토마토 사이에 나누어 붓습니다. 주걱으로 노른자를 가볍게 터뜨려 2~3번만 천천히 저으며 2~4분 익혀 촉촉하게 굳힙니다.

5. 달걀이 원하는 정도로 익으면 즉시 불을 끕니다. 빵 2조각을 곁들여 팬에서 바로 나누어 먹습니다.
