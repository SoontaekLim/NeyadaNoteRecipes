# 황금 볶음밥

![황금 볶음밥 대표 이미지](images/cover.webp)

이연복 셰프의 황금 볶음밥 조리법을 참고해 달걀과 밥을 고슬고슬하게 볶아낸 중식 볶음밥입니다.

- 분량: 2인분
- 분류: 한그릇요리, 중식

## 재료

- 즉석밥 — 2개
- 달걀 — 3~4개
- 스팸 — 약 50g
- 당근 — 약 70g
- 대파 — 약 40g
- 치킨스톡 — 2/3스푼
- 식용유 — 2~3스푼
- 물(스팸 데치기용) — 적당량

## 조리 방법

1. 즉석밥 2개를 전자레인지에 30초간 데워 밥알이 잘 풀리도록 합니다.
2. 볼에 달걀 3~4개를 풀고 데운 즉석밥을 넣은 뒤 나무주걱으로 밥 덩어리를 눌러가며 달걀물이 밥알에 고르게 묻도록 섞습니다.
3. 당근을 잘게 썰어 달걀물에 섞은 밥에 넣고 치킨스톡 2/3스푼도 넣어 골고루 섞습니다.
4. 스팸을 잘게 썰어 끓는 물에 살짝 데친 뒤 건져 물기를 빼고 밥에 섞습니다. 대파도 잘게 썰어 넣고 함께 섞습니다.
5. 팬에 식용유 2~3스푼을 두르고 달군 다음, 준비한 밥과 재료를 모두 넣어 볶습니다.
6. 달걀이 익어 밥이 노릇노릇해지고 밥알이 고슬고슬하게 떨어지면 접시에 담습니다.
