# 황금 볶음밥

![황금 볶음밥 대표 이미지](images/cover.webp)

이연복 셰프의 황금 볶음밥 조리법을 참고해 달걀과 밥을 고슬고슬하게 볶아낸 중식 볶음밥입니다.

- 분량: 2인분
- 분류: 한그릇요리, 중식

## 재료

- 즉석밥 — 2개(각 210g)
- 달걀 — 3개
- 스팸 — 50g
- 당근 — 1/2개(약 70g)
- 대파 — 1/2대(약 40g)
- 치킨스톡 분말 — 2작은술
- 식용유 — 2큰술
- 물(스팸 데치기용) — 500ml

## 조리 방법

1. 즉석밥은 뚜껑을 살짝 열고 전자레인지에서 약 30초 데워 밥알이 쉽게 풀어지도록 합니다.
2. 스팸은 잘게 깍둑썰기한 뒤 물 500ml를 끓여 30초 정도 데치고 건져 물기를 빼 줍니다. 당근과 대파도 잘게 썹니다.
3. 큰 볼에 달걀 3개를 풀고 살짝 데운 밥을 넣어 주걱으로 뭉친 부분을 누르며 밥알마다 달걀물이 고르게 묻도록 섞습니다.
4. 달걀물에 섞인 밥에 당근, 스팸, 대파와 치킨스톡 분말을 넣고 골고루 섞습니다.
5. 팬에 식용유 2큰술을 두르고 중불로 달군 뒤 섞어 둔 밥과 재료를 모두 넣습니다.
6. 주걱으로 계속 저어가며 4~6분간 볶아 달걀이 완전히 익고 밥알이 서로 떨어져 고슬고슬해지면 접시에 담습니다.
