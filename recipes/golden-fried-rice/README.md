# 황금 볶음밥

![황금 볶음밥 대표 이미지](images/cover.webp)

이연복 셰프의 황금 볶음밥 조리법을 참고해 달걀과 밥을 고슬고슬하게 볶아낸 중식 볶음밥입니다.

- 분량: 2인분
- 분류: 한그릇요리, 중식

## 재료

- 밥 — 2공기(약 400g)
- 달걀 — 3개
- 햄 — 80g
- 대파 — 1/2대(약 40g)
- 당근 — 1/4개(약 40g)
- 식용유 — 2큰술
- 소금 — 1/3작은술
- 치킨스톡 분말 — 1/2작은술
- 후추 — 약간

## 조리 방법

1. 대파는 송송 썰고 당근과 햄은 0.5cm 크기로 잘게 썹니다. 밥은 뭉친 부분을 풀어 놓습니다.
2. 달걀을 그릇에 깨서 곱게 풀어 둡니다.
3. 달군 팬에 식용유 1큰술을 두르고 대파를 중불에서 1분 볶아 향을 냅니다.
4. 당근과 햄을 넣고 2분 볶은 뒤 팬 가장자리로 밀어 둡니다.
5. 남은 식용유 1큰술을 두르고 달걀물을 부어 젓가락이나 주걱으로 저어 반쯤 익힙니다.
6. 밥을 넣어 달걀과 채소, 햄이 고르게 섞이도록 센불에서 2~3분 볶습니다. 밥알이 뭉치지 않게 주걱으로 풀어 줍니다.
7. 소금과 치킨스톡, 후추를 넣고 1분 더 볶아 간을 맞춘 뒤 접시에 담습니다.
