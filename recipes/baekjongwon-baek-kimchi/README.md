# 백종원식 백김치

![백종원식 백김치 대표 이미지](images/cover.webp)

SBS <맛남의 광장>의 조리법을 가정용으로 줄인 백김치입니다. 맑은 사이다와 새우젓으로 시원하고 개운한 국물 맛을 냅니다.

- 분량: 2인분
- 분류: 반찬, 한식

## 재료

- 배추 — 1/2포기 (약 800g)
- 굵은 소금 (절임용) — 105g
- 물 (절임용) — 1.5L
- 찹쌀가루 — 6g
- 물 (김칫국물용) — 1L
- 새우젓 — 40g
- 다진 마늘 — 40g
- 양파 — 1/2개
- 사이다 (투명 탄산음료) — 125ml
- 무 — 1/4개 (약 250g)
- 쪽파 — 약 40g
- 홍고추 — 1개

## 조리 방법

1. 배추 1/2포기를 밑동에서 갈라 2쪽으로 나눕니다. 절임용 물 1.5L에 굵은 소금 105g을 녹인 뒤 배추를 담그고, 중간에 한 번 뒤집어 2–3시간 절입니다. 두꺼운 줄기가 부러지지 않고 부드럽게 휘어지면 충분합니다.

2. 절인 배추를 흐르는 물에 2–3번 헹궈 소금기를 씻고, 채반에 엎어 약 30분간 물기를 뺍니다.

3. 김칫국물용 물 1L 중 200ml에 찹쌀가루 6g을 잘 풀어 약불에서 2–3분간 저어 끓여 묽은 찹쌀풀을 만듭니다. 불에서 내려 완전히 식힙니다.

4. 무 1/4개는 가늘게 채 썰고, 쪽파 약 40g은 5cm 길이로, 홍고추 1개는 얇게 어슷썹니다.

5. 양파 1/2개, 새우젓 40g, 다진 마늘 40g, 사이다 125ml를 믹서에 갈아 줍니다. 식힌 찹쌀풀과 김칫국물용 물의 나머지 800ml를 섞습니다. 더 맑은 국물을 원하면 고운 체에 걸러 줍니다.

6. 무채, 쪽파, 홍고추를 가볍게 섞어 물기를 뺀 배추의 잎 사이사이에 조금씩 넣습니다.

7. 속을 채운 배추를 배추 크기에 맞는 좁고 깊은 깨끗한 밀폐 용기에 촘촘히 담고 5단계의 김칫국물을 붓습니다. 누름판이나 깨끗한 작은 접시로 눌러 배추가 국물 아래에 있도록 합니다. 준비한 국물 약 1.2L로 잠기지 않으면 5단계 김칫국물을 같은 재료 비율로 추가로 만들어 부어 줍니다.

8. 직사광선이 없는 서늘한 실온에서 12–24시간 발효한 다음 냉장고로 옮깁니다. 냉장 상태에서 1–2일 더 숙성하고, 맛을 본 뒤 먹기 좋게 잘라 냅니다.

**참고:** [SBS 맛남의 광장 — 백종원의 백김치 레시피](https://programs.sbs.co.kr/enter/2019taste/visualboard/62961?board_no=3625&cmd=view). 방송에 소개된 대량 조리법을 약 1/4 분량으로 줄인 가정용 재구성이며, 원본에서 일부 식재료의 정확한 계량이 확인되지 않아 관련 자료의 추정치를 바탕으로 조정했습니다.
