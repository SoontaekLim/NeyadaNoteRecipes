# 감자채볶음

![감자채볶음 대표 이미지](images/cover.webp)

감자와 당근, 양파를 가늘게 썰어 아삭하고 담백하게 볶은 기본 한식 밑반찬입니다.

- 분량: 2인분
- 분류: 반찬, 한식

## 재료

- 감자 — 2개 (약 300g)
- 양파 — 1/4개 (약 50g)
- 당근 — 1/4개 (약 40g)
- 찬물 — 감자가 잠길 만큼
- 식용유 — 1과 1/2큰술
- 소금 — 1/3작은술
- 후춧가루 — 약간
- 참기름 — 1작은술
- 통깨 — 1작은술

## 조리 방법

1. 감자 2개는 껍질을 벗기고 약 2–3mm 두께로 가늘게 채 썹니다.

   ![1단계 — 채 썬 감자](images/step-1.webp)

2. 감자채를 찬물에 약 5분 담가 전분을 빼고 두어 번 헹군 뒤, 체에 밭쳐 물기를 충분히 뺍니다.

   ![2단계 — 감자채 전분 빼기](images/step-2.webp)

3. 양파 1/4개와 당근 1/4개도 감자채와 비슷한 굵기로 썹니다.

   ![3단계 — 채 썬 양파와 당근](images/step-3.webp)

4. 팬에 식용유 1과 1/2큰술을 두르고 중불로 달군 뒤 감자채와 당근채를 넣어 약 4분간 저어 가며 볶습니다.

   ![4단계 — 감자와 당근 볶기](images/step-4.webp)

5. 양파채를 넣고 2–3분 더 볶습니다. 감자채가 반투명해지고 속까지 익되 모양은 유지될 때까지 볶고, 덜 익었다면 1–2분 더 조리합니다.

   ![5단계 — 양파를 넣고 볶기](images/step-5.webp)

6. 소금 1/3작은술과 후춧가루 약간을 넣어 간을 맞춥니다. 불을 끈 뒤 참기름 1작은술을 섞고 통깨 1작은술을 뿌려 마무리합니다.

   ![6단계 — 통깨를 뿌린 감자채볶음](images/step-6.webp)
