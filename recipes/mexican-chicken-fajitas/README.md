# 치킨 파히타

닭고기와 파프리카를 향신료와 볶아 토르티야에 싸 먹는 텍스멕스 요리.

- 분량: 2인분
- 분류: 텍스멕스, 닭고기

## 재료

- 닭가슴살 — 300g
- 파프리카 — 2개 (약 300g)
- 양파 — 1개 (약 150g)
- 밀 토르티야 — 4장
- 올리브오일 — 2큰술
- 커민 가루 — 1작은술
- 파프리카 가루 — 1작은술
- 칠리 가루 — 1/2작은술
- 소금 — 1/2작은술
- 라임 — 1개

## 조리 방법

1. 닭가슴살을 1cm 폭으로, 파프리카와 양파를 길게 썹니다. 닭고기와 채소는 별도 도마에서 손질합니다.

2. 닭고기에 올리브오일 1큰술, 커민, 파프리카 가루, 칠리 가루와 소금을 넣고 고루 버무립니다.

3. 중강불로 달군 팬에 닭고기를 5~7분 볶아 중심 온도 74℃ 이상으로 완전히 익히고 덜어둡니다.

4. 같은 팬에 남은 올리브오일 1큰술, 파프리카, 양파를 넣고 5~6분 볶습니다. 닭고기를 다시 넣고 1분 더 익힙니다.

5. 토르티야 4장을 마른 팬에서 각 면 20초씩 데워 속재료를 나누어 담고 라임즙을 뿌립니다.
