# 까르보나라

![까르보나라 대표 이미지](images/cover.webp)

생크림 없이 달걀과 파르메산 치즈, 베이컨으로 부드럽고 고소하게 만드는 기본 까르보나라입니다.

- 분량: 2인분
- 분류: 메인 요리, 면요리

## 재료

- 스파게티 — 180g
- 베이컨 — 100g
- 달걀 — 2개
- 달걀노른자 — 1개
- 파르메산 치즈 — 50g
- 굵게 간 후추 — 1/2작은술 + 마무리용 약간
- 물 — 2L
- 소금 — 1큰술

## 조리 방법

1. 냄비에 물 2L를 끓여 소금을 넣고 스파게티를 포장지 권장 시간보다 1분 짧게 삶습니다. 면수 150ml를 덜어 둔 뒤 면을 건집니다.
2. 베이컨은 1cm 폭으로 썰어 팬에 넣고 중약불에서 4~5분 볶아 기름이 충분히 나오고 가장자리가 노릇해지면 불을 끕니다.
3. 볼에 달걀 2개와 달걀노른자 1개, 파르메산 치즈 40g, 후추 1/2작은술을 넣고 고르게 섞습니다. 남은 치즈 10g은 마무리용으로 둡니다.
4. 삶은 스파게티를 베이컨이 있는 팬에 넣고 30초 정도 섞은 뒤 팬을 불에서 완전히 내려 30초 정도 식힙니다.
5. 달걀 치즈 혼합물을 팬에 붓고 빠르게 섞습니다. 면수를 1큰술씩 2~4큰술 정도 더해가며 소스가 윤기 나고 면에 부드럽게 달라붙도록 농도를 맞춥니다.
6. 접시에 담고 남겨 둔 파르메산 치즈와 후추 약간을 뿌려 바로 먹습니다.
