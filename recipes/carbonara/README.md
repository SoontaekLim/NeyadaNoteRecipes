# 까르보나라

![까르보나라 대표 이미지](images/cover.webp)

구안찰레, 달걀노른자, 페코리노 로마노와 후추로 만드는 로마식 까르보나라입니다. 구안찰레는 베이컨으로, 페코리노 로마노는 파르메산 치즈로 대체할 수 있습니다.

- 분량: 2인분
- 분류: 메인 요리, 면요리

## 재료

- 스파게티 — 180g
- 구안찰레 — 100g
- 달걀노른자 — 3개
- 페코리노 로마노 치즈 — 50g
- 굵게 간 후추 — 1/2작은술 + 마무리용 약간
- 물 — 2L
- 소금 — 2작은술

## 조리 방법

1. 냄비에 물 2L를 끓여 소금을 넣고 스파게티를 포장지 권장 시간보다 1분 짧게 삶습니다. 면수 150ml를 덜어 둔 뒤 면을 건집니다.
2. 구안찰레는 1cm 폭으로 썰어 차가운 팬에 넣고 중약불에서 5~7분 천천히 볶아 지방을 충분히 녹이고 가장자리가 노릇해지게 합니다.
3. 볼에 달걀노른자 3개, 페코리노 로마노 40g, 후추 1/2작은술을 넣고 걸쭉하게 섞습니다. 남은 치즈 10g은 마무리용으로 둡니다.
4. 삶은 스파게티를 구안찰레와 녹아 나온 지방이 있는 팬에 넣고 30초 정도 섞은 뒤 팬을 불에서 완전히 내립니다.
5. 팬을 30초 정도 식힌 뒤 달걀노른자 치즈 혼합물을 넣고 빠르게 섞습니다. 면수를 1큰술씩 2~4큰술 정도 더해 소스가 윤기 나고 면에 부드럽게 달라붙도록 농도를 맞춥니다.
6. 접시에 담고 남겨 둔 페코리노 로마노와 후추 약간을 뿌려 바로 먹습니다.
