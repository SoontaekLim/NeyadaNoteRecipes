# 소시지 야채볶음

![소시지 야채볶음 대표 이미지](images/cover.webp)

비엔나소시지와 아삭한 채소를 케첩·고추장 소스에 볶아 만드는 달콤매콤한 밥반찬입니다.

- 분량: 2인분
- 분류: 반찬, 한식

## 재료

- 비엔나소시지 — 250g
- 양파 — 1/2개
- 빨간 파프리카 — 1/2개
- 노란 파프리카 — 1/2개
- 초록 피망 — 1/2개
- 식용유 — 1큰술
- 다진 마늘 — 1작은술
- 토마토케첩 — 3큰술
- 고추장 — 1/2큰술
- 진간장 — 1작은술
- 설탕 — 1작은술
- 물 — 2큰술
- 통깨 — 1작은술

## 조리 방법

1. 비엔나소시지 표면에 얕은 사선 칼집을 2~3개씩 넣습니다. 양파, 빨간 파프리카, 노란 파프리카, 초록 피망은 한입 크기로 썹니다.
2. 볼에 토마토케첩, 고추장, 진간장, 설탕, 물을 넣고 골고루 섞어 소스를 만듭니다.
3. 팬에 식용유를 두르고 중불로 달군 뒤 다진 마늘을 넣어 20~30초 볶아 향을 냅니다.
4. 비엔나소시지를 넣고 2분 정도 볶아 겉면이 살짝 노릇해지도록 합니다.
5. 양파를 넣어 1분 볶은 다음 빨간 파프리카, 노란 파프리카, 초록 피망을 넣고 1~2분 더 볶아 채소의 아삭함을 살립니다.
6. 소스를 붓고 중약불에서 1~2분 볶아 소시지와 채소에 양념이 골고루 묻고 살짝 졸아들게 합니다.
7. 불을 끄고 통깨를 뿌려 마무리합니다.
