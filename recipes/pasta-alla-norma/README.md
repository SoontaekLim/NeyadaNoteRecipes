# 파스타 알라 노르마

구운 가지와 토마토소스를 파스타에 버무리는 시칠리아식 채식 파스타.

- 분량: 2인분
- 분류: 이탈리아, 파스타

## 재료

- 파스타 — 180g
- 가지 — 1개 (약 300g)
- 토마토 통조림 — 400g
- 마늘 — 2쪽
- 올리브오일 — 3큰술
- 바질 — 8g
- 리코타 살라타 또는 파르메산 — 30g
- 소금 — 1작은술 (면수용 별도)

## 조리 방법

1. 가지는 2cm 크기로 깍둑썰고 마늘은 얇게 썹니다. 바질은 씻고 치즈는 갈아 둡니다.

2. 큰 팬에 올리브오일 2큰술을 두르고 가지를 중강불에서 8~10분 굽듯이 볶아 노릇하게 만든 뒤 접시에 덜어둡니다.

3. 같은 팬에 남은 오일 1큰술과 마늘을 넣어 30초 볶습니다. 토마토 400g과 소금 1작은술을 넣고 중약불에서 10분 졸입니다.

4. 파스타 180g을 소금 넣은 끓는 물에 포장지 표기보다 1분 짧게 삶습니다. 면수 100ml를 남겨두고 물기를 뺍니다.

5. 소스에 가지와 파스타를 넣고 면수를 조금씩 더하며 1~2분 버무립니다. 불을 끄고 바질 8g과 치즈 30g을 나누어 올립니다.
