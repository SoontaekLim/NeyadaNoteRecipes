# 콩나물밥

콩나물 향을 밥에 담고 달래 대신 대파 간장 양념을 곁들이는 담백한 한식 한 그릇.

- 분량: 2인분
- 분류: 한식, 밥

## 재료

- 쌀 — 180g
- 콩나물 — 220g
- 물 — 200ml
- 대파 — 25g
- 진간장 — 2큰술
- 참기름 — 1큰술
- 고춧가루 — 1작은술
- 통깨 — 1작은술

## 조리 방법

1. 쌀 180g을 맑은 물이 나올 때까지 씻고 15분 불린 뒤 물기를 뺍니다. 콩나물 220g은 씻어 상한 부분을 제거합니다.

2. 냄비에 쌀과 물 200ml를 담고 콩나물을 고르게 올립니다. 뚜껑을 닫고 중불에서 끓기 시작하면 약불로 줄입니다.

3. 약불로 12분 익힌 뒤 불을 끄고 뚜껑을 열지 않은 채 10분 뜸을 들입니다. 밥알이 단단하면 물을 조금 더 넣고 약불로 추가 조리합니다.

4. 대파 25g을 송송 썰어 간장 2큰술, 참기름 1큰술, 고춧가루 1작은술, 통깨 1작은술과 섞습니다.

5. 밥과 콩나물을 아래에서 위로 살살 섞어 두 그릇에 담고 양념장을 각자 취향에 맞게 조금씩 넣어 비벼 먹습니다.
