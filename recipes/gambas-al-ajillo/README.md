# 감바스 알 아히요 (스페인식 마늘 새우)

새우를 올리브오일에 마늘·말린 고추와 함께 짧게 익히고 바게트를 곁들이는 스페인식 타파스입니다.

- 분량: 2인분
- 분류: 술안주, 메인 요리

## 재료

- 껍질을 벗기고 내장을 제거한 새우 — 300g
- 마늘 — 7쪽
- 올리브오일 — 100ml
- 말린 붉은 고추 — 1개
- 소금 — 1/3작은술
- 생파슬리 — 5g
- 바게트 — 150g

## 조리 방법

1. 새우 300g은 키친타월로 물기를 충분히 제거합니다. 마늘 7쪽은 얇게 썰고 말린 붉은 고추 1개는 반으로 자릅니다. 생파슬리 5g은 잘게 다지고 바게트 150g은 먹기 좋게 썹니다.

2. 작은 팬에 올리브오일 100ml와 마늘, 말린 고추를 넣고 약불에서 3~4분 천천히 데웁니다. 마늘이 연한 황금색이 되면 다음 단계로 넘어가며 갈색으로 태우지 않습니다.

3. 불을 중불로 높이고 새우를 팬에 한 겹으로 넣습니다. 새우 한 면을 약 1~2분 익힌 뒤 뒤집어 반대쪽도 1~2분 익힙니다.

4. 새우가 분홍빛을 띠고 속까지 불투명해지면 소금 1/3작은술을 넣고 불을 끕니다. 오래 익히지 않도록 주의합니다.

5. 생파슬리 5g을 뿌리고 마늘 오일과 함께 바로 냅니다. 바게트 150g을 곁들여 향긋한 오일에 찍어 먹습니다.
