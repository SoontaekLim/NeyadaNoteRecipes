# 소불고기

![소불고기 대표 이미지](images/cover.webp)

얇게 썬 소고기를 달콤짭짤한 간장 양념에 재운 뒤 양파, 대파, 당근과 함께 볶아 만드는 기본 소불고기입니다.

- 분량: 2인분
- 분류: 메인 요리, 한식

## 재료

- 불고기용 소고기 — 300g
- 양파 — 1/2개
- 대파 — 1/2대
- 당근 — 1/4개
- 진간장 — 3큰술
- 설탕 — 1과 1/2큰술
- 다진 마늘 — 1큰술
- 참기름 — 1큰술
- 후춧가루 — 약간
- 식용유 — 1큰술
- 통깨 — 1작은술

## 조리 방법

1. 양파는 0.5cm 두께로 채 썰고, 대파는 어슷하게 썰며, 당근은 가늘게 채 썹니다.
2. 큰 볼에 진간장, 설탕, 다진 마늘, 참기름, 후춧가루를 넣고 설탕이 녹도록 섞어 양념장을 만듭니다.
3. 불고기용 소고기와 손질한 양파, 대파, 당근을 양념장에 넣어 고루 버무린 뒤 20분 정도 재웁니다.
4. 팬에 식용유를 두르고 중강불로 충분히 달군 뒤 재운 소고기와 채소를 넣습니다.
5. 소고기를 풀어가며 5~7분 볶아 완전히 익히고, 팬에 생긴 양념물이 살짝 졸아들 때까지 볶습니다.
6. 불을 끄고 통깨를 뿌려 마무리합니다.
