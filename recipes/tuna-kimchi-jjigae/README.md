# 참치 김치찌개

![참치 김치찌개 대표 이미지](images/cover.webp)

참치와 잘 익은 김치로 간단히 끓이고, 두부를 취향에 따라 더할 수 있는 참치 김치찌개입니다.

- 분량: 2인분
- 분류: 국/찌개, 한식

## 재료

- 잘 익은 김치 — 250g
- 참치 통조림 — 1캔 (135g)
- 두부 (선택) — 1/2모
- 양파 — 1/4개
- 대파 — 1/2대
- 물 — 500ml
- 고춧가루 — 1큰술
- 국간장 — 1큰술
- 다진 마늘 — 1/2큰술
- 식용유 — 1/2큰술

## 조리 방법

1. 김치는 먹기 좋은 크기로 자르고 양파는 채 썹니다. 대파는 어슷 썰고, 두부를 넣을 경우 1.5cm 정도 두께로 썹니다.
2. 냄비에 식용유를 두르고 중불에서 김치와 양파를 2~3분 볶습니다.
3. 물, 고춧가루, 국간장, 다진 마늘을 넣고 끓기 시작하면 중약불로 줄여 약 10분 끓입니다.
4. 참치 통조림의 국물을 가볍게 따라낸 뒤 참치를 넣고 너무 부서지지 않게 한두 번 섞어 약 5분 더 끓입니다.
5. 두부를 넣고 싶다면 두부와 대파를 함께 넣고 3~5분 더 끓입니다. 두부를 넣지 않을 경우 대파만 넣고 한소끔 끓여 마무리합니다.
