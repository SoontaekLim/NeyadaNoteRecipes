# 춘천식 닭갈비

![춘천식 닭갈비 대표 이미지](images/cover.webp)

닭다리살, 양배추, 고구마, 떡과 깻잎을 매콤달콤한 고추장 양념에 볶아내는 춘천식 닭갈비입니다.

- 분량: 2인분
- 분류: 메인 요리, 한식

## 재료

- 닭다리살(정육) — 400g
- 양배추 — 250g
- 고구마 — 150g
- 양파 — 1/2개
- 대파 — 1/2대
- 깻잎 — 8장
- 떡볶이 떡 — 120g
- 식용유 — 1큰술
- 물 — 80ml
- 고추장 — 2큰술
- 고춧가루 — 1과 1/2큰술
- 진간장 — 1과 1/2큰술
- 설탕 — 1큰술
- 맛술 — 1큰술
- 다진 마늘 — 1큰술
- 카레가루 — 1/2작은술
- 참기름 — 1작은술
- 후춧가루 — 약간

## 조리 방법

1. 닭다리살은 한입 크기로 썹니다. 양배추는 4~5cm 크기로, 고구마는 5mm 두께의 반달 모양으로 썰고, 양파는 굵게 채 썹니다. 대파는 어슷 썰고 깻잎은 2cm 폭으로 썹니다. 떡이 딱딱하면 찬물에 10분 정도 담갔다가 물기를 뺍니다.
2. 고추장 2큰술, 고춧가루 1과 1/2큰술, 진간장 1과 1/2큰술, 설탕 1큰술, 맛술 1큰술, 다진 마늘 1큰술, 카레가루 1/2작은술과 후춧가루 약간을 섞어 양념장을 만듭니다.
3. 닭다리살에 양념장의 절반을 넣어 고루 버무린 뒤 10분 정도 둡니다.
4. 넓은 팬을 중불로 달구고 식용유 1큰술을 두릅니다. 양념한 닭다리살과 고구마를 넣어 3분 정도 볶은 뒤 양배추와 양파, 남은 양념장, 물 80ml를 넣고 섞습니다. 뚜껑을 덮어 중불에서 5분간 익힙니다.
5. 뚜껑을 열고 재료가 눌어붙지 않도록 뒤집어 가며 5~7분 더 볶습니다. 닭고기 속까지 완전히 익고 고구마가 부드러워질 때까지 익힙니다.
6. 떡볶이 떡과 대파를 넣고 양념이 고루 묻도록 2~3분 더 볶습니다. 양념이 재료에 고루 배고 팬 바닥에 살짝 걸쭉하게 남을 때까지 볶습니다.
7. 불을 끄기 직전에 깻잎과 참기름 1작은술을 넣고 30초 정도 가볍게 섞은 뒤 바로 담아냅니다.
