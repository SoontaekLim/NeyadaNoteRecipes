# 감자스프

![감자스프 대표 이미지](images/cover.webp)

감자와 양파를 부드럽게 익혀 우유와 함께 곱게 갈아 만든 담백하고 고소한 감자스프입니다. 취향에 따라 마지막에 트러플 오일을 몇 방울 곁들일 수 있습니다.

- 분량: 2인분
- 분류: 국/찌개, 양식

## 재료

- 감자 — 300g
- 양파 — 1/2개(약 100g)
- 버터 — 15g
- 물 — 250ml
- 우유 — 250ml
- 소금 — 1/2작은술
- 후추 — 약간
- 트러플 오일(선택) — 1/2작은술

## 조리 방법

1. 감자는 껍질을 벗겨 2cm 정도로 썰고, 양파는 굵게 썹니다.
2. 냄비에 감자와 양파, 물 250ml를 넣고 끓입니다. 끓기 시작하면 약불로 줄여 뚜껑을 덮고 12~15분간, 감자가 쉽게 으깨질 때까지 삶습니다.
3. 감자와 양파를 건져 한김 식힙니다. 삶은 물은 농도 조절을 위해 조금 남겨 둡니다.
4. 삶은 감자와 양파에 우유 250ml를 넣고 믹서나 핸드블렌더로 곱게 갑니다.
5. 갈아 놓은 스프를 냄비에 붓고 버터 15g을 넣습니다. 약불에서 바닥에 눌어붙지 않도록 저으며 한 번 끓어오를 때까지 데운 뒤 소금 1/2작은술과 후추 약간으로 간합니다. 너무 되직하면 남겨 둔 삶은 물을 조금씩 더합니다.
6. 그릇에 담고 취향에 따라 트러플 오일을 1인분당 몇 방울씩 둘러 마무리합니다.
