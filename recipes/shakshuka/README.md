# 샥슈카

파프리카 향이 나는 토마토소스에 달걀을 깨 넣어 익히는 북아프리카·중동식 팬 요리.

- 분량: 2인분
- 분류: 북아프리카, 브런치

## 재료

- 달걀 — 4개
- 토마토 통조림 — 400g
- 빨간 파프리카 — 1개 (약 150g)
- 양파 — 1/2개 (약 80g)
- 마늘 — 2쪽
- 올리브오일 — 1큰술
- 커민 가루 — 1작은술
- 파프리카 가루 — 1작은술
- 소금 — 1/2작은술
- 빵 — 2조각

## 조리 방법

1. 양파와 파프리카를 1cm 크기로 썰고 마늘을 다집니다. 달걀 4개는 준비해 둡니다.

2. 팬에 올리브오일 1큰술을 달구고 양파와 파프리카를 중불에서 6분 볶아 부드럽게 만듭니다.

3. 마늘, 커민 1작은술, 파프리카 가루 1작은술을 넣고 30초 볶습니다. 토마토 400g과 소금 1/2작은술을 넣어 8분 끓입니다.

4. 소스에 숟가락으로 네 군데 홈을 내고 달걀을 하나씩 깨 넣습니다. 뚜껑을 덮고 약불에서 5~8분 익혀 흰자가 굳도록 합니다.

5. 달걀이 원하는 정도로 익으면 불을 끄고 빵 2조각과 함께 따뜻하게 냅니다. 완전히 익힌 노른자를 원하면 조금 더 가열합니다.
