# 김치말이국수

![김치말이국수 대표 이미지](images/cover.webp)

잘 익은 김치와 김치국물로 만든 새콤달콤한 차가운 육수에 소면, 오이, 삶은 달걀을 곁들인 시원한 한식 국수입니다.

- 분량: 2인분
- 분류: 면요리, 한식

## 재료

- 소면 — 200g
- 잘 익은 배추김치 — 150g
- 김치국물 — 100ml
- 오이 — 1/3개
- 삶은 달걀 — 1개
- 차가운 물(육수용) — 450ml
- 물(소면 삶기용) — 1.5L
- 식초 — 2큰술
- 설탕 — 1~1.5큰술 + 김치 양념용 1/2작은술(선택)
- 국간장 — 1큰술(또는 액젓 1/2큰술)
- 소금 — 약간
- 참기름 — 1작은술
- 통깨 — 1작은술
- 김가루 — 약간(선택)
- 얼음 — 6~8개

## 조리 방법

1. 큰 볼에 차가운 물 450ml, 김치국물 100ml, 식초 2큰술, 설탕 1큰술, 국간장 1큰술(또는 액젓 1/2큰술)을 넣고 잘 섞습니다. 김치의 신맛에 따라 설탕을 최대 1/2큰술 더 넣고 소금으로 간을 맞춥니다. 냉장고에서 충분히 차갑게 보관합니다.

   ![조리 단계 1](images/step-1.webp)

2. 배추김치 150g을 한입 크기로 썰고 참기름 1작은술, 통깨 1/2작은술과 버무립니다. 신맛이 강하면 설탕 1/2작은술을 선택해 넣습니다. 오이 1/3개는 가늘게 채 썰고 삶은 달걀 1개는 반으로 자릅니다.

   ![조리 단계 2](images/step-2.webp)

3. 냄비에 물 1.5L를 끓여 소면 200g을 넣고 포장지에 표시된 시간에 맞춰 약 3~4분 삶습니다. 곧바로 찬물에 2~3번 비벼 헹궈 전분기를 제거하고 체에 밭쳐 물기를 충분히 뺍니다.

   ![조리 단계 3](images/step-3.webp)

4. 소면을 그릇 2개에 나누어 담고 양념한 김치, 채 썬 오이, 삶은 달걀을 올립니다. 차가운 육수를 나누어 붓고 얼음 6~8개를 더합니다. 남겨 둔 통깨 1/2작은술과 선택 재료인 김가루를 뿌려 바로 냅니다.

   ![조리 단계 4](images/step-4.webp)
