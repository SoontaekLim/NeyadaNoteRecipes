# 스웨덴식 미트볼(Köttbullar)

![스웨덴식 미트볼(Köttbullar) 대표 이미지](images/cover.webp)

소고기와 돼지고기를 섞어 부드럽게 빚은 스웨덴식 미트볼에 크림 그레이비, 링곤베리 잼, 감자튀김을 곁들이는 가정식 쾨트불라르입니다.

- 분량: 2인분
- 분류: 메인 요리

## 재료

- 다진 소고기 — 200g
- 다진 돼지고기 — 100g
- 양파 — 1/4개(약 50g)
- 빵가루 — 3큰술(약 15g)
- 우유 — 60ml
- 달걀 — 1개
- 소금 — 1/2작은술
- 후추 — 1/4작은술 + 소스용 약간
- 올스파이스 가루 — 1/4작은술
- 식용유 — 1큰술
- 버터 — 2큰술(약 30g)
- 밀가루 — 1큰술(약 10g)
- 소고기 육수 — 200ml
- 생크림 — 100ml
- 간장 — 1작은술
- 디종 머스터드 — 1작은술
- 냉동 감자튀김 — 300g
- 링곤베리 잼 — 4큰술(약 60g)

## 조리 방법

1. 빵가루 3큰술에 우유 60ml를 섞어 5분 정도 불립니다. 양파 1/4개는 아주 잘게 다집니다.
2. 볼에 다진 소고기 200g, 다진 돼지고기 100g, 불린 빵가루, 다진 양파, 달걀 1개, 소금 1/2작은술, 후추 1/4작은술, 올스파이스 1/4작은술을 넣고 한 덩어리가 될 정도로만 고루 섞습니다.
3. 고기 반죽을 지름 3cm 정도의 한입 크기 미트볼 18~20개로 빚습니다. 냉동 감자튀김 300g은 제품 안내에 따라 오븐이나 에어프라이어에서 노릇하게 익힙니다.
4. 팬에 식용유 1큰술과 버터 1큰술을 중불로 달군 뒤 미트볼을 넣습니다. 굴려 가며 7~9분 정도 익혀 겉면을 고르게 갈색으로 만들고 속까지 익힌 뒤 접시에 덜어 둡니다.
5. 같은 팬의 불을 중약불로 낮추고 남은 버터 1큰술과 밀가루 1큰술을 넣어 1분 정도 저어 볶습니다. 소고기 육수 200ml를 조금씩 부어 덩어리 없이 풀어 줍니다.
6. 생크림 100ml, 간장 1작은술, 디종 머스터드 1작은술, 후추 약간을 넣고 3~4분 저어 끓여 부드럽게 걸쭉한 그레이비를 만듭니다.
7. 미트볼을 소스에 다시 넣고 약불에서 2분 정도 굴려 가며 데웁니다. 그릇에 미트볼과 크림 그레이비를 담고 감자튀김과 링곤베리 잼을 곁들여 냅니다.
