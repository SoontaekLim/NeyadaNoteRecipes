# 그리스식 레몬 닭고기 감자구이 (코토풀로 레모나토)

닭다리와 감자를 레몬·오레가노 양념에 버무려 오븐에서 노릇하게 구운 그리스식 한 접시 요리입니다.

- 분량: 2인분
- 분류: 메인 요리

## 재료

- 뼈 있는 닭다리 — 2개 (총 500g)
- 감자 — 400g
- 레몬 — 1개
- 마늘 — 3쪽
- 올리브오일 — 3큰술
- 말린 오레가노 — 1작은술
- 파프리카 가루 — 1/2작은술
- 소금 — 3/4작은술
- 후춧가루 — 1/4작은술
- 물 — 100ml

## 조리 방법

1. 오븐을 200℃(상하 열)로 예열합니다. 감자 400g은 깨끗이 씻어 큼직한 쐐기 모양으로 자르고, 마늘 3쪽은 껍질을 벗깁니다. 레몬 1개는 반을 갈라 한쪽은 즙을 짜고 다른 쪽은 얇게 썹니다.

2. 큰 볼에 올리브오일 3큰술, 레몬 반 개 분량의 즙, 말린 오레가노 1작은술, 파프리카 가루 1/2작은술, 소금 3/4작은술, 후춧가루 1/4작은술을 섞습니다. 닭다리 2개와 감자·마늘을 넣어 골고루 버무립니다.

3. 오븐용 그릇에 감자를 먼저 펼치고 닭다리는 껍질이 위로 오게 올립니다. 레몬 반 개를 썬 조각을 사이에 넣고 물 100ml를 그릇 가장자리로 부어줍니다.

4. 200℃ 오븐에서 35분 굽습니다. 감자를 한 번 뒤집고 그릇에 고인 육즙을 닭고기에 끼얹은 뒤 15~20분 더 굽습니다. 닭고기 가장 두꺼운 부분의 중심 온도가 74℃ 이상이고 감자가 부드러운지 확인합니다.

5. 오븐에서 꺼내 5분 쉬게 한 다음 닭고기와 감자를 2접시에 나누어 담고 구운 레몬과 팬에 남은 육즙을 곁들입니다.
