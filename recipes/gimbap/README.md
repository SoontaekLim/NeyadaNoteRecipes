# 김밥

![김밥 대표 이미지](images/cover.webp)

달걀, 당근, 시금치, 단무지, 햄을 밥과 함께 김에 말아 만든 기본 가정식 김밥입니다.

- 분량: 2인분
- 분류: 한그릇요리, 한식

## 재료

- 밥 — 400g
- 김밥용 김 — 2장
- 달걀 — 2개
- 당근 — 1/2개(약 80g)
- 시금치 — 80g
- 김밥용 단무지 — 2줄
- 김밥용 햄 — 2줄
- 참기름 — 2작은술
- 소금 — 1/2작은술
- 통깨 — 1작은술
- 식용유 — 2작은술

## 조리 방법

1. 따뜻한 밥 400g에 참기름 1작은술, 소금 1/4작은술, 통깨 1작은술을 넣고 밥알이 뭉개지지 않게 섞은 뒤 한김 식힙니다.
2. 달걀 2개에 소금 한 꼬집을 넣어 풀고, 팬에 식용유 1작은술을 두른 뒤 두툼하게 부쳐 길게 썹니다.
3. 당근은 가늘게 채 썰어 식용유 1/2작은술과 소금 한 꼬집을 넣고 2~3분 볶습니다. 같은 팬에 남은 식용유 1/2작은술을 두르고 시금치와 소금 한 꼬집을 넣어 숨이 죽을 때까지 약 1분 볶습니다.
4. 김밥용 햄은 팬에서 1분 정도 가볍게 데우고, 단무지는 표면의 물기를 닦아 준비합니다.
5. 김발 위에 김 1장을 거친 면이 위로 오게 놓고 밥의 절반을 올려 위쪽 2cm 정도를 남기고 얇고 고르게 펼칩니다.
6. 밥 가운데에 달걀, 당근, 시금치, 단무지, 햄의 절반을 길게 올립니다. 아래쪽부터 재료를 감싸듯 단단히 말고 끝부분이 아래로 가도록 둡니다. 같은 방법으로 한 줄 더 만듭니다.
7. 김밥 겉면에 남은 참기름 1작은술을 얇게 바르고 한입 크기로 썰어 담습니다.
