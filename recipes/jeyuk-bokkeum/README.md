# 제육볶음

![제육볶음 대표 이미지](images/cover.webp)

고추장 양념에 돼지고기와 양파, 대파를 볶아 매콤달콤하게 만드는 기본 제육볶음입니다.

- 분량: 2인분
- 분류: 메인 요리, 한식

## 재료

- 돼지고기 앞다리살 — 300g
- 양파 — 1/2개
- 대파 — 1/2대
- 식용유 — 1큰술
- 고추장 — 2큰술
- 고춧가루 — 1큰술
- 진간장 — 1큰술
- 설탕 — 1큰술
- 다진 마늘 — 1큰술
- 참기름 — 1큰술
- 통깨 — 1작은술

## 조리 방법

1. 돼지고기는 한입 크기로 썰고 양파는 굵게 채 썰며 대파는 어슷하게 썹니다.
2. 고추장, 고춧가루, 진간장, 설탕, 다진 마늘, 참기름을 섞어 양념장을 만듭니다.
3. 돼지고기에 양념장을 넣고 양념이 고루 묻도록 버무립니다.
4. 팬에 식용유를 두르고 중강불로 달군 뒤 양념한 돼지고기를 넣어 4~5분 볶습니다.
5. 돼지고기가 거의 익으면 양파와 대파를 넣고 2~3분 더 볶아 돼지고기를 완전히 익힙니다.
6. 불을 끄고 통깨를 뿌려 마무리합니다.
