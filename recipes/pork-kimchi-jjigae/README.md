# 돼지고기 김치찌개

![돼지고기 김치찌개 대표 이미지](images/cover.webp)

돼지고기와 잘 익은 김치로 끓이는 기본 돼지고기 김치찌개입니다.

- 분량: 2인분
- 분류: 국/찌개, 한식

## 재료

- 잘 익은 김치 — 250g
- 돼지고기 앞다리살 — 150g
- 두부 — 1/2모
- 대파 — 1/2대
- 물 — 500ml
- 고춧가루 — 1큰술
- 국간장 — 1큰술
- 다진 마늘 — 1/2큰술

## 조리 방법

1. 김치는 먹기 좋은 크기로 자르고 돼지고기와 두부, 대파를 손질합니다.
2. 냄비에 돼지고기를 넣고 중불에서 겉면이 익을 때까지 볶습니다.
3. 김치를 넣고 2~3분 더 볶은 뒤 물을 붓습니다.
4. 고춧가루, 국간장, 다진 마늘을 넣고 중약불에서 약 15분 끓입니다.
5. 두부와 대파를 넣고 3~5분 더 끓인 뒤 간을 확인합니다.
