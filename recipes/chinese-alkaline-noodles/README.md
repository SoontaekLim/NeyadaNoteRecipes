# 생중화면 만들기

![생중화면 만들기 대표 이미지](images/cover.webp)

강력분과 식용 베이킹소다로 반죽해 쫄깃하게 만드는 생중화면입니다. 짬뽕, 라멘, 볶음면에 활용하기 좋습니다.

- 분량: 2인분
- 분류: 면요리, 중식

## 재료

- 강력분 — 200g
- 물(반죽용) — 85ml
- 소금 — 2g
- 식용 베이킹소다 — 2g
- 옥수수전분(덧가루) — 10g
- 물(삶기용) — 1.5L

## 조리 방법

1. 물 85ml에 소금 2g과 식용 베이킹소다 2g을 넣고 완전히 녹입니다. 베이킹파우더가 아닌 식용 베이킹소다를 사용합니다.

2. 볼에 강력분 200g을 담고 준비한 물을 조금씩 부으며 젓습니다. 가루가 자잘하게 뭉치면 손으로 꾹꾹 눌러 한 덩어리로 만듭니다.

3. 반죽을 랩이나 밀폐용기에 넣어 마르지 않게 하고 실온에서 30분간 쉽니다. 처음에는 반죽이 단단하고 거칠어도 괜찮습니다.

4. 반죽을 작업대에 놓고 약 5~7분간 누르고 접기를 반복합니다. 다시 덮어 실온에서 20분간 휴지합니다.

5. 반죽을 밀대로 1.5~2mm 두께로 밀어 편 뒤 옥수수전분 10g을 가볍게 뿌립니다. 반죽을 느슨하게 접고 약 2mm 너비로 썬 다음 면발을 풀어 서로 붙지 않게 합니다.

6. 냄비에 물 1.5L를 끓이고 면을 풀어 넣어 2~3분간 삶습니다. 면의 두께에 따라 시간을 조절한 뒤 건져 물기를 빼고 원하는 국물이나 소스에 넣습니다.
