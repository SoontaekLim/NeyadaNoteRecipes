# 참치 김치볶음밥

![참치 김치볶음밥 대표 이미지](images/cover.webp)

잘 익은 김치와 참치를 볶아 달걀을 더한 간단한 한그릇요리로, 취향에 따라 김가루를 곁들입니다.

- 분량: 2인분
- 분류: 한그릇요리, 한식

## 재료

- 밥 — 400g
- 잘 익은 배추김치 — 200g
- 참치 통조림 — 100g(기름을 뺀 양)
- 달걀 — 2개
- 양파 — 1/4개(약 50g)
- 대파 — 1/2대(약 30g)
- 김치 국물 — 2큰술
- 진간장 — 1큰술
- 설탕 — 1작은술
- 식용유 — 1큰술
- 참기름 — 1작은술
- 김가루 — 2큰술(선택)

## 조리 방법

1. 김치는 1~2cm 크기로 썰고 양파는 잘게 다지며 대파는 송송 썹니다. 참치는 체에 밭쳐 기름을 빼고, 달걀 2개는 가볍게 풀어 둡니다.
2. 중불로 달군 팬에 식용유 1/2큰술을 두르고 달걀을 넣어 크게 저어가며 부드럽게 익힌 뒤 접시에 덜어 둡니다.
3. 같은 팬에 남은 식용유 1/2큰술을 두르고 대파와 양파를 1분 정도 볶습니다. 김치와 설탕 1작은술을 넣고 김치가 부드러워질 때까지 3~4분 볶습니다.
4. 밥 400g과 김치 국물 2큰술을 넣어 밥알을 풀어가며 섞습니다. 진간장 1큰술을 팬 가장자리에 둘러 넣고 센불에서 2~3분 볶아 수분을 날립니다.
5. 기름을 뺀 참치와 미리 익힌 달걀을 넣고 참치가 너무 부서지지 않게 1분 정도 가볍게 섞어 볶습니다.
6. 불을 끄고 참기름 1작은술을 섞어 그릇에 담습니다. 원하면 김가루 2큰술을 위에 뿌려 마무리합니다.
