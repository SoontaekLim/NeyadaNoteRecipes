# 소고기 미역국

![소고기 미역국 대표 이미지](images/cover.webp)

소고기 양지와 미역을 참기름에 볶아 깊고 담백하게 끓이는 기본 소고기 미역국입니다.

- 분량: 2인분
- 분류: 국/찌개, 한식

## 재료

- 건미역 — 10g
- 소고기 양지 — 120g
- 참기름 — 1큰술
- 국간장 — 1과 1/2큰술
- 다진 마늘 — 1작은술
- 물 — 1L
- 소금 — 1/4작은술

## 조리 방법

1. 건미역은 찬물에 약 10분 불린 뒤 여러 번 헹구고 물기를 짜서 먹기 좋은 크기로 자릅니다.
2. 소고기 양지는 키친타월로 겉의 핏물을 닦고 한입 크기로 자릅니다.
3. 냄비에 참기름과 소고기를 넣고 중불에서 약 2분, 소고기 겉면이 익을 때까지 볶습니다.
4. 불린 미역과 국간장을 넣고 2~3분 더 볶아 미역과 소고기에 간이 배도록 합니다.
5. 물을 붓고 센불에서 끓인 뒤 끓기 시작하면 중약불로 낮춰 약 20분 끓입니다.
6. 다진 마늘을 넣고 5분 더 끓인 뒤 소금을 넣어 간을 맞추고 불을 끕니다.
