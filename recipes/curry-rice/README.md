# 카레라이스

![카레라이스 대표 이미지](images/cover.webp)

돼지고기, 양파, 당근을 볶아 쿠민 향을 더하고 고형 카레로 부드럽게 끓여 밥에 얹는 가정식 카레라이스입니다.

- 분량: 2인분
- 분류: 메인 요리, 한그릇요리

## 재료

- 밥 — 2공기(약 400g)
- 돼지고기 — 200g
- 양파 — 1개
- 당근 — 1/2개
- 고형 카레 — 약 40g
- 물 — 350ml
- 식용유 — 1큰술 + 달걀 프라이용 약간(선택)
- 쿠민 가루 — 1/2작은술
- 후추 — 1/4작은술
- 달걀 — 2개(선택)

## 조리 방법

1. 양파는 한입 크기로 썰고 당근은 1cm 정도 두께로 썹니다. 돼지고기도 한입 크기로 준비합니다.
2. 냄비에 식용유 1큰술을 두르고 중불에서 돼지고기를 3~4분 볶아 겉면이 익도록 합니다.
3. 쿠민 가루와 후추를 넣어 30초 정도 더 볶아 향을 냅니다.
4. 양파를 넣고 4~5분 볶다가 뚜껑을 덮고 2분 정도 두어 양파가 부드러워지고 수분이 나오게 합니다. 당근을 넣어 2분 더 볶습니다.
5. 물 350ml를 붓고 끓기 시작하면 중약불로 낮춰 10분 정도 끓여 당근과 돼지고기를 충분히 익힙니다.
6. 불을 약하게 줄이고 고형 카레를 조금씩 넣어 완전히 풀어 줍니다. 바닥이 눋지 않도록 저으며 4~5분 더 끓여 농도를 맞춥니다.
7. 선택으로 달걀을 준비한다면 팬에 식용유를 약간 두르고 달걀 프라이를 만듭니다. 밥을 그릇에 나누어 담고 카레를 얹은 뒤 달걀 프라이를 곁들입니다.
